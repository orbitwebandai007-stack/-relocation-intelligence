# Worthwhile — Relocation Intelligence Portfolio Case Study
## Screen 01: Main Relocation Dashboard

![Worthwhile Main Relocation Dashboard](/mockups/screen1_main_dashboard.png)

### Design Specifications & UI Architecture
- **Viewport:** 16:9 Desktop (1920 × 1080)
- **Primary Accent:** Forest Emerald (`#176B50`)
- **Secondary Accent:** Electric Lime (`#C8E6A0`)
- **Dark Surface:** Obsidian Slate (`#111A15`)
- **Base Canvas:** Warm Off-White (`#F8F9F7`)
- **Key Modules:**
  1. **Top Navigation Cockpit:** Worthwhile brand mark, route switcher (`Lucknow → Bengaluru · Outer Ring Road`), compensation badge (`₹24 LPA`), and profile avatar.
  2. **Interactive Map Canvas:** High-contrast road corridors connecting workplace hub to residential clusters.
  3. **Double Pill Marker:** Merged workplace and locality capsule (`Office: Bellandur EcoWorld | #1 Bellandur · ₹32k`).
  4. **Active Route HUD:** Real-time distance (`14.8 km`), peak commute (`28 min`), and net surplus (`+₹48,500/mo`).
  5. **Decision Intelligence Sidebar:** Multi-factor relocation score gauge (`92/100 Highly Favourable`), shortlisted corridors list, and primary CTA.
